# UI Tokens — Chess Training Dashboard

*Note: Tokens are design-direction-dependent. These are placeholders until a direction is selected. Each design mockup in the compare phase has its own token set.*

## Color Naming Convention
```
--bg:          #F8F6F3 (warm off-white)
--surface:     #F0EDE8 (warm light beige)
--ink:         #2D2A24 (warm charcoal)
--ink-muted:   #8B8178, #6B6560 (warm taupe)
--accent:      #B8653A (warm terracotta / rust)
--border:      #E0DCD4, #D4CEC6 (warm beige lines)
--muted:       #B0A89A (pale taupe)
--success:     #B8653A (accent doubles as success)
```
